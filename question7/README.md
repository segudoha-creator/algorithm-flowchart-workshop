# Question 7 — Area of Rectangle

## Task

Input the length and width of a rectangle, then calculate and display its area.

## Pseudocode

START
INPUT length
INPUT width

SET area = length * width

OUTPUT area

END

## Flowchart

```mermaid
flowchart TD
    A([Start]) --> B[/Input length/]
    B --> C[/Input width/]
    C --> D[Set area = length * width]
    D --> E[/Output area/]
    E --> F([End])
```

## Example

If:

* Length = 7
* Width = 5

Then:

Area = 7 * 5 = 35
